# 演示素材说明

首页的截图和 34 秒视频来自 StructBoard 的真实白色界面，使用虚构的 NOVA 演示管线。模型以公开的 [1UBQ](https://www.rcsb.org/structure/1UBQ) 与 [1PGA](https://www.rcsb.org/structure/1PGA) 示例坐标构造演示变体；这些组合和数值用于展示操作，不代表真实设计结果、预测质量或实验结论。

截图完整保留软件窗口；视频保持窗口比例，字幕位于软件画面外。视频含中文合成配音和程序制作的原创配乐，GIF 为其无声片段。

MCP 画面展示外部演示客户端通过 MCP 发起的一次真实只读工作区查询。该演示连接与构境内置 AI 助手是两个独立入口；拍摄后已撤销测试授权。素材没有包含真实项目目录、个人研究条目、配对码、API Key 或客户信息。

软件内置的 Aurora 演示另由 `demo_data.py` 完全生成，不需要下载这些公开结构。
